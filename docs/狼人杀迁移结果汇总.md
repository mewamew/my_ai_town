## 八、关键技术踩坑记录

1. **GDScript 无参方法名在链式访问（`.has/.get/[]/for-in`）中是 Callable 而非调用** → 必须用属性 getter（`var x: T: get: return ...`）
2. **Godot `--script` 模式**：`_initialize` 报错后 `quit()` 不执行 → 进程空转；测试必须自调 quit 或提前 return + finish
3. **Godot 运行时 `load()` 在 `_initialize` 会死锁**（资源加载器重入）→ 探针必须 `preload`
4. **host 动态访问返回无类型**：`var x := host.method()` 推断失败，需显式类型（如 `var deferred_to_dawn: bool = ...`）
5. **advance 参数是"真实秒"**（1 秒 = 1 游戏分钟，`realSecondsPerGameMinute=1.0`）；旧测试误写 `5*1440*60` 秒 = 300 天
6. **存档校验白名单**：新增 socialState 字段（money/reputation）必须同步 `TownWorldRestorePeople` 白名单，否则 `SAVE_SNAPSHOT_INVALID`
7. **数据指纹链**：任何 occupation/activity 数据变更会改变 activity source fingerprint → 需重建 `town_world.json` 并更新 `TownSaveSchemaRegistry` 终点指纹常量

## 十一、投票/夜间技能改动作类型 + 限流可编辑化（2026-08-25）

### 11.1 起因：模型无视附件字段（"没人投票"根因）

- **投票功能代码链路全部正常，是模型无视 `exile_vote` 附件**：收到"本轮必须提交 exile_vote…"强约束，真实 API 实测（`diag_vote_live.gd`，38 次真实决策，deepseek-v4-flash-0731 + thinking disabled）**0 次输出 exile_vote**，0 票流会；居民台词知道要投票（"快到投票的时候了，我去广场等着"）但决策里就是不带附件字段。
- 推论：`night_skill` 附件（医生守诊/学者查验）同为附件 → 大概率同样从未生效（与"白芷整晚收不到守诊选项"现象吻合，`3744db1` 只修了提交侧）。
- 探针 `diag_vote_probe.gd`（纯本地，注入 3 卧底+警察+医生）验证链路全通：11:00 大会候选 19 → `vote_snapshot` forced → wake.exile_vote → prompt 渲染含"必须提交"→ 提交链 reject/落账 → 12:30 开票放逐，**checks=26**（后随夜间技能场景扩到 34）。
- **中心广场投票根因**：`prompts/background/10_town_common_knowledge.md` 旧文案"每天上午 11:00 镇民大会在公告栏宣布开始" + "广场上有公告栏" → 模型两步推理"大会在公告栏宣布 → 公告栏在广场 → 去广场投票"。投票约束本身从不提广场。已改 L17 明确：**"投票不需要去任何地方（不用去广场、不用去公告栏），你的决策里会出现'投票放逐'动作，直接在决策里提交即可"**。

### 11.2 方案 A：投票放逐 = 即时动作类型（提交 `c9ab2fb`，11 文件 +824/-9）

模型对动作类型遵守度高（暗杀/制服/攻击实测全部正常输出），投票从"附件字段"改为**动作类型**：

| 文件 | 改动 |
|---|---|
| `game/agent/AgentContract.gd` | `ACTION_TYPES` 加 `投票放逐`；`ACTION_FIELDS` 加 `["action_id","type","target_resident_name","line"]`（**用名字不用 id**，与候选名单一致） |
| `game/world/runtime/action/TownActionTypeRegistry.gd` | `ALL_TYPES` + `TABLE_TYPES` 的 T4_required_fields 加 `投票放逐`（否则 registry 测试 minimal 放行断言 FAIL） |
| `game/world/runtime/action/TownActionValidation.gd` | `ACTION_FIELDS` + `validate_action_shape` 分支：`require_action_texts(action, ["target_resident_name","line"])` |
| `game/agent/prompt/AgentPromptCompiler.gd` | `_build_derived_constraints` 把 exile_vote 转成 `actions["投票放逐"]`（targets=候选、required=forced、双通道兼容）；渲染加"（本轮必填）"；提交模板"投票不需要去任何地方，直接在决策里提交即可" |

| `game/world/runtime/TownWerewolfRuntime.gd` | `submit_vote` `-> void` 改 `-> String` 返回细分错误串（不在候选/已投/不 alive 等），空=成功 |

测试：`diag_vote_probe` checks=34（新增完整提交链场景）；`town_world_action_type_registry_test` **83**；`town_world_foundation_test` **1528**（动作类型 16→17 两处断言）。

### 11.3 夜间技能 = 「使用技能」动作类型（提交 `7c21feb`，9 文件 +207/-10）

同模式：动作类型「使用技能」字段 `["action_id","type","skill_id","target_resident_name","line"]`。

- 5 个文件同投票放逐改法（AgentContract / TypeRegistry / Validation / PromptCompiler / SubmissionRuntime）；`TownRoleSkillRuntime.submit_night_skill` `void`→`String` 返回细分错误（窗口未开/医生已提交/学者次数用尽/skill_id 无效等）。
- **PromptCompiler 渲染器原本不认识 `skills` 键**（只渲染 targets）→ 加 `if data.has("skills"): text += "；可用技能：%s"`，否则模型看不到 `skill_id` 该填什么。
- 技能常量：`SKILL_DOCTOR="doctor_protect"`（白芷）/ `SKILL_SCHOLAR="scholar_inspect"`（许照）/ `SKILL_FRAME="undercover_frame"`（卧底嫁祸）；`NIGHT_START_MINUTE=1200`（20:00）/ `DAWN_MINUTE=480`。
- **白名单/契约核查结论**（用户问"会不会碰到白名单校验"）：整条提交链校验点全部放行——ACTION_TYPES 已加（AgentContractAction L194 / AgentContractEnvironment L105 / DecisionExecution L127/L136 都查它）；字段白名单按新 ACTION_FIELDS；`_validate_action_environment_references` 对所有动作类型执行（line 台词过物件白名单，与暗杀/制服同等，非使用技能特有风险）；实测无效 skill_id 的错误来自 `submit_night_skill` 本身（说明契约校验已放行）。
- 测试：`diag_vote_probe` checks=34（夜间场景：开票后 advance 到 1200 → 白芷 wake.night_skill → prompt 含 skill_id/doctor_protect → 无效 skill_id 拒绝 → 有效提交落账）；registry **87**；foundation **1607**（17→18 两处断言）。

### 11.4 限流参数可编辑化（提交 `9d0a655`）

7 个限流常量 `const` → `static var`（引用名不变），新增 `_init` + 静态配置加载：

- **覆盖优先级**：环境变量 `AI_TOWN_THROTTLE_CONFIG` 指定的 JSON 文件 > 默认 `user://config/throttle.json`（即 `%APPDATA%\Godot\app_userdata\我的ai小镇\config\throttle.json`）> 内置默认值。
- **`--script` 测试模式跳过配置**（不读环境变量、不读文件）→ 测试进程永远用默认值，改配置不污染回归。
- **键**：`max_concurrent_model_requests`(3) / `rate_limit_retry_delay_seconds`(2.0) / `rate_limit_retry_delay_max_seconds`(4.0) / `dispatch_rate_per_second`(0.5) / `throttled_dispatch_rate_per_second`(0.35) / `rate_limit_throttle_duration_ms`(30000) / `max_dispatch_budget`(3.0)。
- **坑**：`_dispatch_budget := MAX_DISPATCH_BUDGET` 实例初始化器在 `_init` 前运行 → `_init` 里覆盖 static var 后必须重赋。
- 示例：`docs/throttle.example.json`（默认值，复制到 user:// 路径改键即可，重启生效）。
- 回归：`diag_throttle` checks=13 / `agent_test` 1004 / `continuity` PASS。

### 11.5 测试执行怪癖（重要）

`Start-Process` + `RedirectStandardOutput` 跑 Godot 测试**有时整批卡死**（stdout 只有 Godot 横幅、零输出、超时、Kill 无残留，连正常测试都卡）；**前台直接跑正常**：`& $godot --headless --path ... --script res://tests/X.gd 2>&1`。后续一律前台跑。
