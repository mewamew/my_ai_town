## 八、关键技术踩坑记录

1. **GDScript 无参方法名在链式访问（`.has/.get/[]/for-in`）中是 Callable 而非调用** → 必须用属性 getter（`var x: T: get: return ...`）
2. **Godot `--script` 模式**：`_initialize` 报错后 `quit()` 不执行 → 进程空转；测试必须自调 quit 或提前 return + finish
3. **Godot 运行时 `load()` 在 `_initialize` 会死锁**（资源加载器重入）→ 探针必须 `preload`
4. **host 动态访问返回无类型**：`var x := host.method()` 推断失败，需显式类型（如 `var deferred_to_dawn: bool = ...`）
5. **advance 参数是"真实秒"**（1 秒 = 1 游戏分钟，`realSecondsPerGameMinute=1.0`）；旧测试误写 `5*1440*60` 秒 = 300 天
6. **存档校验白名单**：新增 socialState 字段（money/reputation）必须同步 `TownWorldRestorePeople` 白名单，否则 `SAVE_SNAPSHOT_INVALID`
7. **数据指纹链**：任何 occupation/activity 数据变更会改变 activity source fingerprint → 需重建 `town_world.json` 并更新 `TownSaveSchemaRegistry` 终点指纹常量
