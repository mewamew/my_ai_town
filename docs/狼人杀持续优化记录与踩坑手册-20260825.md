## 六、踩坑手册（全部实测，按频率排序）

### 6.1 GDScript 语言坑
1. **Variant 链式 `:=` 推断失败（最高频，踩 8+ 次）**：`var x := host.WEREWOLF_RUNTIME.xxx(...)`（host 无类型标注）→ Parse Error: Cannot infer the type。**必须显式 `var x: String =` / `var x: Dictionary =`**。踩坑点：TownWerewolfRuntime:525、TownRoleSkillRuntime:456/467、TownWerewolfRuntime submit_vote、SubmissionRuntime 即时分支、TownAgentWakeContextRuntime police_device_state、TownAnnouncementResidentRuntime（有标注可 :=）
2. **GDScript 无参方法名在链式访问中是 Callable 非调用**：`.has()/.get()/[]/for-in` 直接写方法名会拿到 Callable → 必须用属性 getter（var x: T: get: return ...）
3. **换行链式 `(x as Dictionary\n.get(...))` 解析失败**（Parse Error: Cannot call on an expression）→ 拆中间变量
4. **static var 实例初始化器顺序**：`var _dispatch_budget := MAX_DISPATCH_BUDGET` 在 _init 前运行 → 配置覆盖 static var 后必须重赋
5. **typed Array 参数**：`_witness_names` 要求 Array[String]，普通 Array 传入 SCRIPT ERROR 中断函数（钩子静默 false）→ 函数内显式 for 循环转 typed
6. **`--script` 模式 root Window 不在场景树**：`root is inside tree = false`，add_child 后 is_inside_tree 仍 false → 树内分支（预算限速/对话绕过）无法单测，只能游戏实战验证
7. **SceneTree 脚本 _initialize 报错后 quit() 不执行** → 进程空转；测试必须自调 quit 或提前 return+finish
8. **运行时 load() 在 _initialize 死锁**（资源加载器重入）→ 探针必须 preload

### 6.2 测试执行坑
9. **Start-Process + RedirectStandardOutput 跑 Godot 测试会卡死**（stdout 只有横幅零输出）→ **必须前台跑**：`& $godot --headless --path <game> --script res://tests/<名>.gd 2>&1`（或批量 foreach+Select-String）
10. **Godot debug 构建 SCRIPT ERROR 只打 stderr 且中断当前函数**：world.call 不存在方法 → 返回 null → 后续断言全跳过 → **仍打 PASS（假阳性）**！探针必须检查 stderr
11. **官方测试断言失败打在 stderr，前缀 `TOWN_WORLD_AGENT_PASS_FAIL:`**（不含 ERROR 字样）→ grep 要抓 `PASS_FAIL` 而非 ERROR
12. **RedirectStandardOutput/RedirectStandardError 不能同一文件**（Start-Process 限制）
13. **批量顺序跑遇卡死会阻塞整批** → 进程级超时（WaitForExit(90000)+Kill）或前台逐个跑
14. **注入测试居民 display name 空** → 候选名单尾部空名（_resident_display_name 查不到）→ 投票/技能不能投注入居民（投官方居民如林岚/唐小满）

### 6.3 契约层坑（动作/事件白名单）
15. **AgentContract.EVENT_TYPES 白名单**：自定义事件 type（追踪情报/查案线索/暗杀未遂）必须加进白名单，否则 wake events 校验失败 → 决策 REJECTED + CONTINUITY_FALLBACK（闻叙 4 次实证）
16. **AgentContractAction._validate_action**：字段白名单按 ACTION_FIELDS[type]；elif 链外的类型跳过额外校验；L194 action.type 合法性查 ACTION_TYPES
17. **_validate_action_environment_references 物件白名单**（对所有动作执行）：line/narration 提到当前地点没有的物件被拒（官方防幻觉）——B 类不迁，police.md 教模型"短台词"
18. **canonicalize_decision `for field in ACTION_FIELDS[action_type]`**：动作类型与字段表必须同步加，否则 KeyError
19. **validate_action_shape require_action_texts**：动作必填字段在此声明（投票放逐/使用技能/追踪/查案都要加分支）
20. **测试计数断言**：`ALL_TYPES.size()==N` 两处（town_world_action_type_registry_test.gd:50 + town_world_foundation_test.gd:5870）每次加动作类型都要同步
21. **官方测试硬依赖 line/narration 物件白名单**：6 个断言（"广场待着不能凭空生成长椅"等）→ 相关改动属 B 类不迁

### 6.4 模型行为坑

### 6.6 Git 坑
35. **.git-commit-msg.txt 会被 git add -A 误提交** → git rm --cached + commit --amend --no-edit；或 git add 明确文件清单
36. **提交 message 中文引号转义** → Out-File -Encoding utf8 + git commit -F + Remove-Item
37. **测试注入居民在 _advance_to_minute_of_day 后位置会变** → 探针先 advance 再 _place 全量复位
38. **探针 advance 参数单位**：world.call("advance", float(delta)) 是游戏分钟（1 秒=1 分钟，5*1440*60=300 天是错的）
