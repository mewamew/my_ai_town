## 1. 三核心模块：狼人杀住进 runtime 根目录

拆分后狼人杀不再是 TownWorldRuntime.gd 里的一段，而是三个独立 `world/runtime/` 根文件：

| 模块 | 文件 | 职责 |
|---|---|---|
| 昼夜/投票/胜负 | `game/world/runtime/TownWerewolfRuntime.gd`（638 行） | 夜间暗杀延迟公布、镇民大会投票回合、胜负判定、警察追踪装置 |
| 夜间技能/警察行动 | `game/world/runtime/TownRoleSkillRuntime.gd` | 医生守护、学者查证、卧底栽赃帧、警察制服/查案/追踪配额 |
| 卧底期限 | `game/world/runtime/TownUndercoverDeadlineRuntime.gd`（45 行） | 第 5 天未杀完 → 第 6/7/8 天处决；无辜全灭警察失败 |

三者均为 `extends RefCounted` + 全静态函数，不持有实例状态；**所有状态挂在 `world._werewolf_state`（Dictionary）**，随存档 `werewolfState` 域读写。挂载点见下文 §5。

## 2. 时间常量（以代码为准）

`TownWerewolfRuntime.gd` L11-18（唯一事实源）：

| 常量 | 值 | 语义 |
|---|---|---|
| `NIGHT_START_MINUTE` | 1200（20:00） | 入夜，夜间技能回合开启 |
| `DAWN_MINUTE` | 480（08:00） | 天亮：统一公布昨夜死讯 + 结算夜间技能 |
| `VOTE_START_MINUTE` | 480（08:00） | 镇民大会开始（天亮即开会） |
| `VOTE_REMIND_MINUTE` | 720（12:00） | 强制唤醒未投票居民补投 |
| `VOTE_SETTLE_MINUTE` | 750（12:30） | 开票放逐 |
| `EXILE_REASON` | "被镇民大会投票放逐" | 放逐死亡原因 |
| `POLICE_DEVICE_DURATION_MINUTES` | 1440（1 天） | 警察追踪装置时长 |

> ⚠️ 代码注释里残留「11:00 开会」字样（文件头 L5、start_vote_round L302），**与常量不符，以常量 480=08:00 为准**（2026-08-24~26 已把开会时间从 11:00 提到天亮 08:00，注释未同步）。

### 时间线（一天）

```
20:00 入夜 ── 卧底可暗杀(每夜一刀) / 医生守护 / 学者查证 / 卧底栽赃帧
08:00 天亮 ── ① flush 昨夜暗杀死讯(统一公告) ② 结算夜间技能 ③ 镇民大会开始
08:00-12:30 投票窗口 ── 全程强制(exile_vote 必填, 12:00 补唤醒漏投者)
12:30 开票 ── 最高票放逐(平票无人出局), 卧底被放逐当场曝光身份
23:59 期限检查 ── TownUndercoverDeadlineRuntime.check_deadline
```

## 3. 三个模块逐个拆解

### 3.1 TownWerewolfRuntime：昼夜 / 投票 / 胜负

**夜间暗杀与延迟公布**
- `is_night(minute)`：`minute_of_day >= 1200 or < 480`（20:00-08:00）
- `night_index(minute)`：20:00 开始的夜属于当天，00:00-08:00 仍算前一晚
- `undercover_kill_available(world, minute)`：非终局 + 夜间 + 本夜未动过手；**全体卧底每晚最多一刀**，被医生挡下同样消耗当晚机会
- `record_night_kill` / `undercover_kill_quota_exhausted`：记账 + wake 快照注入（提示卧底今晚不能再杀）
- `defer_night_death_announcement(event, previous_doing)`：夜间 + reason 含"暗杀" → 死讯入 `pendingDeathAnnouncements` 队列，**不即时公告、不落公开日志、表现层遮罩死亡外观**
- `flush_pending_death_announcements`（08:00）：批量公告 "清晨，……" → 补记公共事件日志 → 表现层切换已死外观 → 唤醒全体在世居民
- `pending_death_presentation`：UI/感知投影遮罩，返回 `{"pending":true,"previousDoing":...}`

**警察警觉护盾**
- `police_alert_charges` / `consume_police_alert`：警察每局 1 次警觉免死（暗杀警察被挡下），存 `policeAlertCharges`，default_state 置 1

**警察追踪装置**（`POLICE_DEVICE_TRACKER="tracker"`）
- 单一槽位，装新目标覆盖旧目标，时长 1 天；一次安装同时获得：目标对话（原窃听）+ 行踪目的地（原定位）+ 重大行动上报
- `install_police_device` / `police_device_state` / `police_device_active`；存 `policeDevices`

**镇民大会投票**（核心玩法）
- `advance(world, minute)`：整点挂载——480 天亮 flush+胜负补发 → 480 开会 → 720 补投 → 750 开票
- `start_vote_round`（08:00）：仅 `feature_active`（世界存在卧底）+ 非终局 + 第 1 天起 + 在世 ≥3 人；**候选人排除警察**（警察可投票但不可被投）；广播 "12:30 举行放逐投票"；唤醒全体在世居民（伴随当前动作）
- `remind_unvoted_residents`（12:00）：只唤醒未投票居民，携带 `forced` 标记
- `vote_snapshot(world, resident_id)`：进 `wake_packet.snapshot.exile_vote`，含 `round_day / settle_clock:"12:30" / candidate_ids（排除自己）/ forced`
- `_vote_forced`：`VOTE_START <= 当前分钟 < VOTE_SETTLE` 全程强制
- `submit_vote(world, resident_id, value)`：返回错误串，空串=成功；校验：未开会/终局/死者/重复投票/目标非空/目标在候选名单；**容错**：模型有时抄 "ID｜名字" 混合格式 → 先 `split("｜")[0]` 截断再校验；一票不能改
- `settle_vote_round`（12:30）：先清空回合 → 终局作废 → 按 target 计数 → **平票或流会无人出局** → 最高票 `confirm_resident_death(exile_id, EXILE_REASON)`；卧底被放逐 → 公告 "离开时身份曝光——他竟是潜伏在镇上的卧底！"

**胜负判定**
- `check_victory(world)`（由 confirm_resident_death 末尾调用）：`undercover_alive==0` → 镇民胜；`innocent_alive==0 or innocent_alive<=undercover_alive` → 卧底胜；世界无卧底居民时特性不激活（避免普通死亡误发"卧底已清除"）
- 终局锁 `gameOver=true`；**夜间终局不即时广播**（`_night_silence_active`），胜负公告压到次日 08:00 先公布死讯再宣布胜负（`announce_pending_victory`）
- 公告文案：镇民胜 "小镇终于恢复安宁…" / 卧底胜 "小镇彻底沦陷…"

**状态域**（`default_state`，全部随存档走）

```gdscript
{
  "pendingDeathAnnouncements": [],  # 夜间待公布死讯队列
  "vote": {},                       # 进行中的投票回合 {day, votes, candidateIds}
  "gameOver": false,
  "winner": "",
  "winnerAnnounced": false,         # 胜负公告是否已发出(夜间终局压到天亮)
  "roleSkills": ROLE_SKILL_RUNTIME.default_role_skills(),
  "undercoverKillLastNight": -1,    # 全卧底阵营每晚最多 1 杀
  "policeAlertCharges": 1,          # 警察每局 1 次警觉免死
  "policeDevices": {},              # 警察追踪装置(单一槽位)
}
```

### 3.2 TownRoleSkillRuntime：夜间技能 + 警察行动

**身份常量**（L12-17）

| 常量 | 值 |
|---|---|
| `DOCTOR_ID` | `resident_bai_zhi_01`（白芷） |
| `SCHOLAR_ID` | `resident_xu_zhao_01`（许照） |
| `SKILL_DOCTOR` | `"doctor_protect"`（医生守护） |
| `SKILL_SCHOLAR` | `"scholar_inspect"`（学者查证） |
| `SKILL_FRAME` | `"undercover_frame"`（卧底栽赃帧） |

**配额常量**：`SCHOLAR_CHARGES_MAX=3`、`POLICE_CHARGES_MAX=2`、`TRACKER_CHARGES_MAX=3`、`INVESTIGATE_DAILY_LIMIT=2`（查案每天限 2 次）、`SUBDUE_SUSPENSION_MINUTES=180`（制服后暂停）

**夜间技能回合**
- `advance`：20:00 `start_night_round`（唤醒医生/图书管理员/所有卧底提交 night_skill，force_fresh 保证新快照）→ 08:00 `resolve_night` 结算（医生守护 `_resolve_doctor` / 学者查证 `_resolve_scholar` / 卧底栽赃）→ `_clear_night_submissions`
- `night_skill_snapshot(world, resident_id)`：仅技能持有者且未提交者非空；含 `skills / candidate_ids`；进 `wake.snapshot.night_skill`
- `submit_night_skill(world, resident_id, value)`：**双通道**——既接受决策附件 `night_skill`，也接受"使用技能"即时动作（TownActionValidation L182-189 校验 `skill_id/target_resident_id/line` 必填）
- `is_assassination_blocked` / `consume_frame_for_death` / `frame_clue_for_event`：医生守护挡暗杀；卧底死亡现场栽赃线索

**警察行动配额**
- 制服：`police_can_subdue` / `police_charges_remaining` / `record_subdue_result`（SUBDUE_SUSPENSION_MINUTES=180）
- 追踪装置：`police_tracker_charges` / `consume_police_tracker`
- 查案：`police_investigate_remaining` / `consume_police_investigate`（每天限 2 次）

### 3.3 TownUndercoverDeadlineRuntime：卧底期限（45 行，全静态）

| 常量 | 值 | 语义 |
|---|---|---|
| `POLICE_JOB` | "警察" | 警察失败判定角色 |
| `DEADLINE_DAYS` | 5 | 第 5 天结束前必须杀完 |
| `EXECUTION_DAYS` | [6, 7, 8] | 逾期后每天处决一个卧底 |
| `CHECK_MINUTE` | 1439（23:59） | 每天最后一分钟检查 |

`check_deadline`：无辜全灭 → `_undercover_declare_police_failed`（警察失败）；`day in [6,7,8]` 且卧底存活 → 处决第一个在世卧底，reason="卧底任务逾期未完成，组织按规矩处决" + 组织公告。

## 4. 决策双向传递：wake 注入 + 提交链（全链路）

## 6. 与旧版《狼人杀化改造记录.md》的差异（重要）

旧版记录（2026-08-17 之前，巨石时代）已过时，**以本文为准**：

| 项 | 旧版（已过时） | 新架构（当前代码） |
|---|---|---|
| 开会/开票 | "18:00 开会 19:30 开票" | 08:00 开会（VOTE_START=480）、12:00 补投、12:30 开票（VOTE_SETTLE=750） |
| 投票载体 | 决策附件 `exile_vote` 唯一通道 | **双通道**：附件 exile_vote + "投票放逐"即时动作；Gateway 方案 C 快速通道 |
| 技能载体 | 附件 | 附件 night_skill + "使用技能"即时动作双通道 |
| 警察窃听/定位 | 分列装置 | 合并为单槽位追踪装置（监听+定位+重大行动一体，1 天） |
| 警察免死 | — | 每局 1 次警觉护盾（policeAlertCharges=1） |
| 卧底暗杀节奏 | 每夜一刀 | 同，但被医生挡下同样消耗当晚配额（undercoverKillLastNight） |
| 夜间死亡公布 | 即时/延迟语义不同 | 统一：夜间暗杀延迟到 08:00 天亮批量公布 |
| 胜负公布 | 即时 | 夜间终局压到天亮（先死讯后胜负） |
| 卧底期限 | 旧方案无 | TownUndercoverDeadlineRuntime：第 5 天期限、第 6/7/8 天处决 |
