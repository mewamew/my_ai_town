# 第 4 层：冲突与关系系统精讲（新架构版）

> 目标：理解"争执/攻击/斗殴"状态机怎么运作、关系亲密度怎么积累，
> 以及这对狼人杀（暗杀现场、警察查案、身份怀疑）意味着什么。
>
> 对应文件（新架构）：
> - 冲突域：`game/world/runtime/conflict/`（7 个模块）
> - 关系域：`game/world/runtime/relationship/`（3 个模块）
> - Agent 侧：`game/agent/conflict/`（AgentConflictContract + AgentConflictIntent）
>

> 关系从"证据→深度"升级为"旅行者关系运行时"（对话/互动/攻击都产生亲密度增量）。

## 1. 冲突系统（conflict/ 7 模块地图）

| 模块 | 职责 |
|---|---|
| `TownConflictRuntime.gd` | ★冲突主运行时：状态机（见下）+ 阶段推进 |
| `TownConflictWorldController.gd` | 冲突向世界的投影/命令入口 |
| `TownConflictWorldCoordinationRuntime.gd` | 冲突公开命令、分钟推进、投影、事件知识、日志与世界版本提交的统一协调 |
| `TownConflictAgentWorldBridge.gd` | ★Agent-世界桥：冲突快照注入 wake 包（`conflicts`/`conflict_injuries`/`conflict_tension_options`），
| | 唤醒集合管理 |
| `TownConflictTensionOptionProjection.gd` | 张力选项投影：真实冲突依据、公开人设动机、玩家缺席、对话中附加攻击选项 |
| `TownConflictKnowledgeProjector.gd` | 冲突知识投影（目击/知晓传播——猫鼠玩法的灵魂） |
| `TownConflictJudgments.gd` | 纯函数族：冲突起因/动机/空投影判断 |

**状态机常量**（`TownConflictRuntime.gd`）：
- 阶段：`PHASE_UNILATERAL_HIT`（单方动手）/ `PHASE_BRAWL`（斗殴）/ `PHASE_ENDED`（结束）
- 攻击类型：居民 `["unarmed","improvised"]`（徒手/顺手），玩家化身另有类型
- 数值：轻伤恢复 `DEFAULT_LIGHT_RECOVERY_MINUTES=180`、重伤治疗 `DEFAULT_HEAVY_TREATMENT_MINUTES=120`、
  斗殴最多 `DEFAULT_MAX_BRAWL_ROUNDS=4` 轮、张力过期 `DEFAULT_TENSION_EXPIRY_MINUTES=180`、
  对手冷却 `DEFAULT_PAIR_COOLDOWN_MINUTES=360`、事件历史 `MAX_EVENT_HISTORY=256`

**冲突五类是即时结算**（不进推进循环）：
`争执 / 攻击 / 回应冲突 / 介入冲突 / 离开冲突`——由冲突桥 `execute_action` 直接产出动作结果，
全程不写 `resident["currentAction"]`（见第 3 层注册表注释，这是有意设计）。

**Agent 侧**：
- `agent/conflict/AgentConflictContract.gd` —— 冲突动作的字段合同（含历史踩过的 kill 别名）
- `agent/conflict/AgentConflictIntent.gd` —— 冲突意图结构
- 冲突后的"受伤必须反应"：`runtime/agent/TownAgentDecisionAcceptancePolicy.gd` 在合同层强制
  受伤居民只能回应

## 2. 冲突全流程（举例：一次攻击）

```
1. 判定能否冲突   TownConflictWorldController（在场/冷却/起因）
2. Agent 提交攻击  agent/conflict/AgentConflictContract 校验（目标在 nearby）
3. 即时结算        conflict/TownConflictRuntime（execute_action 直出结果，不进推进）
   ├─ 单方动手     PHASE_UNILATERAL_HIT → 伤害/受伤状态（condition/ 域管伤势推进）
   ├─ 升级斗殴     PHASE_BRAWL（最多 4 轮）
   └─ 结束         PHASE_ENDED → 结果入队 → 事件广播
4. 知识传播        conflict/TownConflictKnowledgeProjector（目击/听说 → 谁知道了什么）
5. 张力延续        conflict/TownConflictTensionOptionProjection（下次 wake 给受害者的反应选项）
```

## 3. 关系系统（relationship/ 3 模块）

| 模块 | 职责 |
|---|---|
| `TownTravelerRelationshipRuntime.gd` | ★旅行者关系运行时：处理对话/互动记录，产出亲密度 |
| `TownTravelerRelationshipState.gd` | 关系状态（存档 schema `traveler-relationship` v1） |
| `TownRelationshipEvidenceProgress.gd` | 关系证据进度（对话→深度） |

**关键常量**（`TownTravelerRelationshipRuntime.gd`）：
- `MAX_PROCESSED_CONVERSATIONS=128` / `MAX_PROCESSED_INTERACTIONS=256`（只处理最近 N 条，防无限膨胀）
- 亲密度增量：对话 `AGENT_AFFINITY_DELTA_MIN=-5` ~ `MAX=5`；玩家攻击 `AVATAR_ATTACK_AFFINITY_DELTA=-10`
- 熟悉度分档：`FAMILIARITY_LABELS` + 对话阈值 `FAMILIARITY_CONVERSATION_THRESHOLDS=[0,1,3,6,12,24]`
  （0 次陌生 → 1 次点头之交 → 3 次熟人 → 6 次 → 12 次 → 24 次深交）
- 变更历史上限 `MAX_AFFINITY_CHANGE_HISTORY=32`

**机制**：
- 居民间关系 = **对话/互动事件**驱动的亲密度（证据→数值）
- 玩家与居民：攻击会 -10（动了手关系崩）
- 关系状态进存档（`traveler-relationship` schema v1），恢复时读回
- Agent 侧：`agent/prompt/AgentPromptCompiler.gd` 的 `_render_traveler_relationship()`（L1079）
  把关系档位渲染进提示词，居民才知道"我和谁熟/和谁不熟"

## 4. 对狼人杀改造的意义

1. **暗杀现场**：目击机制＝冲突知识投影（`TownConflictKnowledgeProjector`）——
   "谁在场看到了什么"决定情报不对称
2. **警察查案**：怀疑度可以挂关系证据（对话多=熟，反常行为=疑），
   警察记忆（`agent/memory/`）+ 数据库合成"情报"（`TownAgentWakeContextRuntime._police_intel_context`）
3. **身份怀疑的戏剧性**：关系系统的"谁知道什么"与狼人杀"谁会信谁"天然吻合——
   熟人的话更可信（亲密度高 → 记忆权重/提示词倾向）
4. **医生救助**：重伤治疗 120 分钟在 `condition/`（诊所）域处理，医生守诊技能
   （`TownRoleSkillRuntime.SKILL_DOCTOR`）挂夜间，与冲突伤势恢复联动
5. **嫁祸技能**（`SKILL_FRAME=undercover_frame`）：卧底把冲突/嫌疑引向别人——本质是
   "伪造事件知识"，知识投影层就是它的落点
